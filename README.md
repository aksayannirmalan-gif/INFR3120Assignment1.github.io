Gradients


I decided to use a linear gradient on the banner to make it more appealing for all html files. For angled gradients, I decided that it should be on the footer, considering how I used linear gradients on the header of the page . I also used linear gradients on the body to make the content on the website pop up more


Color scheme


I decided to go for a light blue and a turquoise theme for the body, header, footer and around the outside of the body of my website. I picked these colors because they looked nice and blended well with each other. In addition I choose an off white color for the wrapper so that areas not covered by the header and footer, and the outside of the body can be more easier to read. I kept the black color for the text because it pops out more and is more noticeable when the website first opens 


Viewports


The viewport for full sized screens like laptops are 960 pixels. The viewport for tablets can be between 481 pixels and 960 pixels. The viewport of phones have to be 480 pixels. These viewports had to be used because it is the minimum or maximum pixels each type of device has.


Fluid


To make the website more fluid I made sure to use the percent sign (%) instead of using the pixels (px) because it would make the website transition more smoothly when changing screen sizes
